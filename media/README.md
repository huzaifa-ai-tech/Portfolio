# Original media

Full-quality source images for the portfolio site, kept in the repository so the
originals are always available for future use (resumes, social previews,
re-exports at other sizes, etc.).

| File | Used for |
| --- | --- |
| `*.png` (project names) | The `Selected Projects` cards. The site serves optimized WebP versions from `Portfolio/public/images/` (1280px wide, quality 88); these PNGs are the untouched originals. |
| `logo.png` | Site logo / favicon source (512x512, transparent). The site serves `src/assets/logo.webp` and `public/favicon.png` derived from it. |

Nothing in this folder is copied into the built site — it lives only in the
repository.
